## About Me

I am a Computer Engineering student at K.J. Somaiya School of Engineering, Mumbai, passionate about building intelligent, practical software. My work spans GenAI and RAG systems, applied machine learning, and full-stack web and mobile development.

I enjoy taking an idea from raw data to a deployed product: ingesting and indexing data, developing models, and exposing them through clean, secure APIs and user interfaces. I care about responsible AI, privacy-first design, and building systems that people can trust and understand.

## What I Do

- Build LLM and Retrieval-Augmented Generation applications with re-ranking, source citations, and guardrails
- Develop predictive and recommendation models using Python and modern ML frameworks
- Create full-stack applications with React, Django, FastAPI, and Flutter
- Mentor students in machine learning and participate in AI hackathons
